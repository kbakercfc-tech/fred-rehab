Fred's Rehab App - How to Use

1. Enter Data

On the "Enter Data" page, you can log Fred's daily activities:

  • Date: Select the date for the entry.
  • Exercise Done: Choose 'Yes' or 'No' to indicate if the daily exercise was completed.
  • Weights Done: Choose 'Yes' or 'No' to indicate if the weight training was completed.
  • Steps Walked: Enter the total steps for the day.
  • Comments: Add any relevant notes or observations.

Use 'Save Exercise' and 'Save Steps' to save data. Saving new data for a date will overwrite any previous entry for that date.

2. Enter Data - Tabular

This page allows for quick entry of multiple days' data:

  • Select Date Range: Choose a start and end date (up to 30 days).
  • Click 'Generate Table' to populate a table.
  • For each date, you can enter 'Exercise Done', 'Weights Done', 'Steps', and 'Comments'.
  • Click 'Save All Data' to save all entries for the displayed dates.

3. View History

This page displays a tabular list of all logged activities.

4. View Steps Graph

Visualize Fred's steps progress over time:

  • Filter and Sort: Filter by date range ('All', 'Last 30 Days', 'Custom') and sort by 'Date' (earliest first) or 'Steps' (least first).
  • Chart Type: Toggle between "Line Chart" and "Bar Chart" views.
  • Legend: The color of the bars indicates the exercise status for that day. A red outline marks the day with the most steps in the selected period.

5. Calendar View

See activity at a glance. Days are color-coded:

  • Dark Green: Exercises & Weights Done
  • Blue: Only Weights done
  • Green: Only Exercises Done
  • Grey: No exercise or weights done
  • Red: Nothing Entered

6. Exercise Videos

Manage and view exercise videos. You can upload new videos or delete existing ones.

7. Fitbit Integration

Automatically sync Fred's steps from his Fitbit account:

  • Connection: Use the 'Connect Fitbit' button on the 'Enter Data' or 'Data Management' pages to link Fred's account.
  • Syncing: Once connected, click 'Sync from Fitbit' to automatically pull in the daily steps. On the Tabular page, use 'Sync All' to fetch multiple days at once.
  • Automatic Notes: The app will add an 'Auto-sourced from Fitbit' comment to every entry fetched this way.

8. Data Management

Keep Fred's records safe with manual and automatic backups:

  • Manual Backup: Download a full archive (ZIP) of the database and all videos to your computer at any time.
  • Automatic Backups: Set a frequency (Daily, Weekly, Monthly) to have the server automatically save a rolling history of the last 7 backups.
  • Restore: In an emergency, you can upload a previous ZIP backup to restore all data. Note: This will overwrite all current entries.
